# The Real History v6

A Foundational Truth Project atlas. This first release explores historical evidence across the Americas and pilots a Lower Mississippi timeline. Colonial claims, administration and Indigenous locations are distinguished; historical borders are not reconstructed.

Open The-Real-History-v6.html offline. The date slider swaps three locally embedded Library of Congress scan previews and linked-only archive views; claim, administration, Indigenous places and modern locations are independently toggleable source-linked reference points. Scans are not georeferenced to the points; no historical polygons have been created. The original Americas feed and World orientation view remain. A network connection is only needed for offsite records. Build with python package_offline.py; verify with node test_offline.cjs.


The map previews are from the Library of Congress; item links and reuse notes appear in the atlas. The orientation map uses Natural Earth. Archive links are references, not a claim to license those sites or third-party translations.
